📌 快速安裝與建置指南

只需簡單四個步驟，即可在您的電腦上啟動 G321 Controller

1

安裝 Equalizer APO 底層驅動

請先下載並安裝 Equalizer APO 在安裝過程中的 Configurator 視窗，請務必勾選你的 Logitech G321 播放裝置，完成後重新啟動電腦

下載 Equalizer APO
2

安裝 Python 依賴套件

開啟命令提示字元 (CMD) 或 PowerShell，執行以下指令安裝必要套件：

pip install PyQt6 pycaw pystray Pillow comtypes
3

執行主程式

將專案檔案下載至本地資料夾後，直接執行主程式：

python g321_controller.py
4

(可選) 使用 PyInstaller 打包為 .exe 執行檔

若希望打包為無命令視窗的獨立執行檔，請執行以下指令：

pyinstaller --noconsole --onefile --icon=g321icon.ico g321_controller.py
